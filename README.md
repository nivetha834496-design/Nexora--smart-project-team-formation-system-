# Smart Project Team Formation System

# Project Overview

       Smart Project Team Formation System is a web-based application designed to help educational institutions and organizations create balanced and efficient project teams. The system automatically forms teams based on students' skills, interests, experience levels, and project requirements, ensuring effective collaboration and improved project outcomes.
The project is being developed using Python Flask as the backend framework and MySQL as the database management system.
